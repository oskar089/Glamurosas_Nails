# Booking checks

- **Preselection:** selecting an acrylic service opens the booking page with that service reflected in the copy.
- **Google Calendar flow:** the booking page links to the official Google Calendar appointments schedule and opens it in a new tab.
- **No local booking form:** the page no longer asks for name, email, service, date, or time.
- **No local submission:** the page does not post personal details to `/api/bookings` from the client UI.

All scenarios run at desktop and mobile viewport sizes without entering sample personal details.
