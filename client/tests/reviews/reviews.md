# Demo review checks

- Empty submission identifies the required rating and focuses the first radio.
- Native arrow-key navigation selects five stars; a short comment is rejected.
- Valid sample text containing HTML syntax renders as text rather than creating an image or executing code.
- Success adds a fourth, explicitly local review, clears the form, and produces no storage entries or non-GET requests.
- Reloading removes the local review and restores the three labeled examples.
